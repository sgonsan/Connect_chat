# Connect Chat

A Discord-clone real-time chat application with text and voice/video channels.

## Phase 2 — Voice/Video Channels

Voice and video channels powered by LiveKit SFU are now available.

- See [VOICE_CHANNEL_SETUP.md](./VOICE_CHANNEL_SETUP.md) for setup instructions
- Voice channels appear under a "Voice Channels" section in the sidebar with 🔊 prefix
- Click a voice channel to join — your camera and microphone will be requested
- Use the control bar to mute, toggle camera, or leave the room
